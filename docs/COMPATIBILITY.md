The current bounded acceptance reconciliation supports all 27 original collaboration/harness/memory checks, including positive Claude selected-existing-session continuation. This is a bounded subset, not an overall acceptance percentage or a platform PASS. Unsupported attach can be accurately labeled and offered a dedicated worker, but cannot satisfy a promised compatible-session proof.

There is no promised user count or latency SLO. The [capacity measurements](MEASURED_CAPACITY.md) cover one synthetic owner's concurrent authenticated sessions, local chat/files and an ascending 1/4/12/24-session workload on a two-vCPU, 3 GiB Ubuntu VM. They exclude browser rendering, internet latency and provider inference. Use those results with their limits when sizing a deployment.
